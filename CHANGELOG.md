# KEV Data Change Log
This file tracks additions, modifications, and removals in the Known Exploited Vulnerabilities (KEV) dataset.

Entries below are **auto-generated by the changelog workflow** whenever KEV data files are updated in this repository.

---

## Format
Each entry includes:
- **Date** (Eastern Time)
- **Commit link** for traceability
- **Source commit message**
- Sections:
  - **Ransomware Tag Changes** — highlights flips in `knownRansomwareCampaignUse`
  - **Added** — new CVEs introduced
  - **Modified** — existing CVEs with field-level changes
  - **Removed** — CVEs removed from the dataset
  - **Files** — confirms which KEV data files changed
